# ADR 0002：项目资源边界与 PDF/HTML 支持等级

状态：已接受
日期：2026-07-13

## 背景

旧组件在包内拼接 `../` 读取论文图片和 Bib，无法跨项目复用；分页 PDF 与流式 HTML 也不能共享全部页面规则。

## 决策

- 最低 Typst 0.15.0。
- 图片和参考文献路径必须在调用方用 `path(...)` 构造，或直接传 bytes/content。
- PDF 是正式视觉目标；HTML 通过 `target()` 跳过分页、页眉页脚等结构，仅保证内容可读。

## 后果

- 公共接口会明确拒绝裸字符串资源路径。
- PDF 和 HTML 可以共享正文语义，但允许外壳有意降级。
- 0.14.x 不在兼容范围内。
