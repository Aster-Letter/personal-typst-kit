# 当前方案

状态：v0.2.0 实施基线
最后更新：2026-08-15 (Asia/Shanghai)

## 项目定位

建立可安装的个人 Typst 文档工具包，以统一视觉基底覆盖论文、书稿、技术指南和学习者讲义，并保持对 AI 友好的稳定公共接口。

## 技术路线

- 最低 Typst 0.15.0，包形结构但暂不发布 Typst Universe。
- PDF 正式支持；HTML 使用 `target()` 提供实验降级。
- `lib.typ` 单入口；内部按 foundation、themes、components、profiles、extensions 分层。
- Windows/Linux CI 编译；本地精选页人工视觉审阅。

## 模板演进流程

- 真实消费者需求依次经过语义归类、中性最小复现、API 决策、包内回归和外部验证。
- 外部项目通过薄适配器保留业务语义和旧调用签名，公共包不吸收学生字段、私人路径或项目图形代码。
- 参数化本地冒烟测试验证跨工作区消费者；正式步骤见 `../docs/TEMPLATE_EVOLUTION.md`。

## v0.2.0 范围

- 五个 profile、五个主题、通用组件与四类扩展。
- `working-paper` 提供正式工作论文结构、结构化作者、中英文摘要与三种前置布局。
- 学术扩展提供按节共享计数的定理类、证明、正文注释、致谢与附录。
- `paper` 继续保留随和定位，并修复正文页码与中文标题层级。
- Windows/Linux 本地包安装脚本和字体检查说明。
- 中性示例、主题画廊、合法/非法配置测试。
- MIT 许可证与私有 GitHub 仓库。

## 后置事项

- Typst Universe 发布、正式 HTML 版面、macOS 自动安装器、像素级视觉回归。
- 公开仓库前的隐私、字体和样例素材复核。
